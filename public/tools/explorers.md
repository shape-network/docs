# Explorers

| Explorer | Focus |
| --- | --- |
| Shapescan | Block explorer: transactions, contracts, verification |
| Shapescan Sepolia | Testnet block explorer |
| Deca | NFT explorer: collections, metadata, floor prices |
| Zapper | Portfolio and activity feed in a human-readable format |

Verify your contracts on Shapescan to make them readable. See [Deploy a Contract](https://docs.shape.network/quick-start/deploy-a-contract.md) for verification steps.

- [Shape Mainnet Explorer](https://shapescan.xyz/)

- [Shape Sepolia Testnet Explorer](https://explorer-sepolia.shape.network/)

- [Deca](https://deca.art/): See all NFTs on Shape in one place

- [Zapper](https://zapper.xyz/): See what's happening onchain in a human readable way
