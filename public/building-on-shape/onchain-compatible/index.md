# Onchain Compatible Projects

A collection of projects made with interoperability in mind

- [Assembly](https://docs.shape.network/building-on-shape/onchain-compatible/assembly.md): A flexible ERC1155 system for creating and crafting composable items

- [OTOM by Kjetil Golid](https://docs.shape.network/building-on-shape/onchain-compatible/otom.md): Create and experiment with particles called otoms

- [Moveable Type by DEAFBEEF](https://moveabletype.deafbeef.com/)
