# Start Building on Shape

Shape is an EVM-compatible L2 on the [Optimism Superchain](https://www.optimism.io/superchain). Gasback returns 80% of sequencer fees to contract owners.

- [Connect to Shape](https://docs.shape.network/quick-start/connect-to-shape.md): Configure viem, wagmi, Foundry, and ethers.js for Shape

- [Deploy a Contract](https://docs.shape.network/quick-start/deploy-a-contract.md): Deploy and verify a smart contract with Foundry

- [Build a dApp](https://docs.shape.network/building-on-shape/builder-kit.md): Scaffold a full-stack dApp with the Shape Builder Kit
