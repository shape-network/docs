# Run a Node

Learn how to run your own Shape Mainnet and Shape Sepolia nodes.

Shape runs on the [OP Stack](https://docs.optimism.io/), so running a Shape node is the same as running a standard OP Stack node with Shape-specific configuration files. You will need two components:

- **op-geth** (execution client) — processes transactions and maintains state
- **op-node** (consensus client) — derives the L2 chain from L1

## Prerequisites

### Hardware Requirements

| | Full Node | Archive Node |
| --- | --- | --- |
| CPU | 4+ cores | 8+ cores |
| RAM | 16 GB | 16 GB |
| Storage | 1 TB SSD (NVMe recommended) | 15+ TB SSD (NVMe recommended) |

Storage requirements grow over time. Plan for roughly 100 GB additional disk every six months for a full node.

### Software Requirements

- [Go](https://go.dev/dl/) 1.23 or later
- A C compiler (gcc or clang)
- [Git](https://git-scm.com/)
- An L1 Ethereum RPC endpoint (e.g. from [Alchemy](https://www.alchemy.com/), [Infura](https://www.infura.io/), or your own node)
- An L1 beacon chain (consensus layer) endpoint

### Build op-geth

```bash
git clone https://github.com/ethereum-optimism/op-geth.git
cd op-geth
make geth
```

### Build op-node

```bash
git clone https://github.com/ethereum-optimism/optimism.git
cd optimism/op-node
make op-node
```

## Setup

### 1. Generate a Shared Secret

op-geth and op-node communicate over the Engine API, authenticated with a shared JWT secret:

```bash
openssl rand -hex 32 > jwt.txt
```

### 2. Initialize op-geth

Download the `genesis.json` for your network (see below) and initialize the data directory:

```bash
geth init --datadir=datadir genesis.json
```

## Shape Mainnet

Download these configuration files:

- [rollup.json](https://arweave.net/Lh9vjNsHKHOKzGwWwlvVz2tsxcL_h5Wc-Ga0udO3Xm0)
- [genesis.json](https://arweave.net/LrSrsEJsUtSWNAzkpKqkwE9RG3JZP1SmlOQNlTu8Nxk)

### Run op-geth (Mainnet)

```bash
geth \
  --datadir=datadir \
  --http \
  --http.port=8545 \
  --http.addr=0.0.0.0 \
  --authrpc.addr=localhost \
  --authrpc.jwtsecret=jwt.txt \
  --authrpc.port=8551 \
  --ws \
  --ws.port=8546 \
  --ws.addr=0.0.0.0 \
  --syncmode=full \
  --gcmode=full \
  --maxpeers=0 \
  --nodiscover \
  --rollup.sequencerhttp=https://mainnet.shape.network \
  --rollup.disabletxpoolgossip
```

For an archive node, change `--gcmode=full` to `--gcmode=archive`.

### Run op-node (Mainnet)

```bash
op-node \
  --l2=http://localhost:8551 \
  --l2.jwt-secret=jwt.txt \
  --rollup.config=rollup.json \
  --l1=<YOUR_L1_RPC_URL> \
  --l1.beacon=<YOUR_L1_BEACON_URL> \
  --rpc.addr=0.0.0.0 \
  --rpc.port=8547 \
  --override.granite=1727370000 \
  --override.holocene=1740139200
```

Replace `<YOUR_L1_RPC_URL>` with your Ethereum L1 RPC endpoint and `<YOUR_L1_BEACON_URL>` with your L1 beacon chain endpoint.

```bash
geth \

  --maxpeers=0 \
  --nodiscover \
  --rollup.sequencerhttp=https://sepolia.shape.network \
  --rollup.disabletxpoolgossip
```

### Run op-node (Sepolia)

```bash
op-node \
  --l2=http://localhost:8551 \
  --l2.jwt-secret=jwt.txt \
  --rollup.config=rollup.json \
  --l1=<YOUR_L1_SEPOLIA_RPC_URL> \
  --l1.beacon=<YOUR_L1_SEPOLIA_BEACON_URL> \
  --rpc.addr=0.0.0.0 \
  --rpc.port=8547 \
  --override.ecotone=0 \
  --override.fjord=1721732400 \
  --override.granite=1727197200 \
  --override.holocene=1739880000 \
  --override.pectrablobschedule=1742925600
```

Replace `<YOUR_L1_SEPOLIA_RPC_URL>` with your Sepolia L1 RPC endpoint and `<YOUR_L1_SEPOLIA_BEACON_URL>` with your Sepolia beacon chain endpoint.

## Troubleshooting

If your node is stalling, failing to find peers, or otherwise unresponsive, try passing the bootnode enodes directly with `--p2p.bootnodes` in op-node:

### Missing beacon endpoint

If you see an error like `ecotone upgrade scheduled but no beacon endpoint is configured`, you need to provide an L1 beacon chain endpoint using the `--l1.beacon` flag when running op-node.
